# TPC_1: Manipulação de Strings em Python

Este repositório contém a resolução dos exercícios focados em algoritmos de manipulação de strings. 

## 📋 Índice dos Exercícios

1.  **Inverter String**: Reversão de uma string usando *slicing*.
2.  **Contar Caracteres**: Contagem de ocorrências ("a" e "A") e uso de `Counter`.
3.  **Contar Vogais**: Verificação de vogais numa string (iterativo e *list comprehension*).
4.  **Converter para Minúsculas**:
    * Método nativo (`.lower()`).
    * Implementação manual.
5.  **Converter para Maiúsculas**:
    * Método nativo (`.upper()`).
    * Implementação manual.
6.  **Verificar Capicua**: Deteção de palíndromos (case-insensitive).
7.  **Strings Balanceadas**: Verificação de subconjuntos de caracteres.
8.  **Ocorrências de Substring**:
    * Implementação manual com ciclo `while`.
    * Método nativo (`.count()`).
9.  **Anagramas**: Verificação usando `collections.Counter`.

## Tecnologias e Dependências

* **Linguagem:** Python
* **Bibliotecas:** `collections` (para a classe `Counter`)
